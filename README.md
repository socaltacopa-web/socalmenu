# SoCal Tacos Self Ordering Website

Static self-ordering kiosk website for SoCal Tacos.

## GitHub Pages

This folder is ready to publish with GitHub Pages.

1. Upload the files in this folder to a GitHub repository.
2. In GitHub, open the repository settings.
3. Go to Pages.
4. Set the source to the `main` branch and `/root`.
5. Save.

GitHub will publish `index.html` as the website homepage.

## Files

- `index.html` - website page
- `self-ordering-restaurant.css` - website styling
- `self-ordering-restaurant.js` - menu, cart, owner tools, and ticket printing
- `socal-tacos-logo-cropped.png` - header logo
- `socal-tacos-logo.png` - original logo image
